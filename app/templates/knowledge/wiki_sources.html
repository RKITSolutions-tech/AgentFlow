Wiki folders

A wiki folder is a folder of markdown pages, either on this machine or on a remote AgentFlow instance, that acts as a project's knowledge store. Agent sessions can be given it as starting context and, with AgentFlow tools on, search it and record decisions in it. The folder must be under the allowed project roots of the machine it lives on.
